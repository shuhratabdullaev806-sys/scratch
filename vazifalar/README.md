# Vazifalar bazasi

`baza.js` — saytda ishlatiladigan tayyor baza (vazifalar va javoblar kaliti).

Javoblari bor Word fayllar (`docx/`) **GitHub'ga yuklanmaydi** (`.gitignore`da).
Ular faqat o'qituvchi kompyuterida saqlanadi.

## Bazani yangilash
1. Word fayllarni `vazifalar/docx/` papkasiga qo'ying (kompyuterda).
2. `python vazifalar/docx_to_baza.py` ni ishga tushiring (`pip install python-docx`).
3. Yangilangan `vazifalar/baza.js` ni GitHub'ga yuklang.
